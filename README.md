# Python Module 00 – Fundamentals



## Description
Python Module 00 is an introductory project of the 42 core.
Its main goal is to introduce the fundamentals of Python programming and problem-solving.

Through a set of small, focused exercises, this module covers:
- Basic syntax and data types
- User input and output
- Conditional statements
- Iterative and recursive approaches
- Function design and file organization

Each exercise is isolated in its own directory (`ex0`, `ex1`, etc.) and is designed to encourage clean, readable, and logical code following 42 standards.

## Algorithms and Technical Choices

 - This project uses simple and explicit algorithms to match the educational goals of Module 00.

 > Iterative algorithms
  - Used to demonstrate loop-based logic, allowing step-by-step control of execution and state changes.

 > Recursive algorithms
  - Used to introduce recursion, focusing on base cases and reducing problems into smaller subproblems.

 > Linear traversal
  - Lists and data structures are processed sequentially to ensure clarity and predictability.

These choices prioritize readability, correctness, and learning value over optimization, which is appropriate for a beginner-level module.
